Timer per soal

Menjawab benar saat sisa waktu masih separuh atau lebih memberi +1 bintang bonus. Waktu habis tidak membuat jawaban salah — anak tetap boleh menjawab, hanya bonusnya hilang. Berlaku di kuis, benar/salah, sortir, dan tebak profesi (permainan bersoal).

Bagian yang tampil
🏆 Papan bintang tersimpan
Semua room yang pernah dibuat / dimasuki di perangkat ini.

Papan bintang tersimpan per-browser (localStorage), jadi tiap perangkat pemain punya papannya sendiri.

Password disimpan sebagai hash di browser ini, bukan teks polos. Namun proteksi ini berjalan di sisi browser dan hanya cukup untuk melindungi pengaturan tampilan — jangan menyimpan data sensitif di aplikasi ini. Untuk keamanan permanen, ganti juga adminPassword di config.js sebelum deploy.

Salin JSON ini lalu tempel nilainya ke window.APP_CONFIG di file config.js agar menjadi pengaturan permanen untuk semua pengunjung. Atau simpan sebagai backup.
